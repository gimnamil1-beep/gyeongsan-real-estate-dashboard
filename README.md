# 경산행운부동산 — 경산시 부동산 대시보드

경산시 아파트 Top 10, 거래 흐름, 추천매물과 입지분석을 제공하는 공인중개사 브리핑용 대시보드입니다.

## 공개 배포

`main` 브랜치에 푸시하면 GitHub Actions가 `gyeongsan-dashboard/public` 폴더를 GitHub Pages에 배포합니다.

공개 저장소에는 API 키를 저장하지 않습니다. GitHub Pages에서는 브리핑용 샘플 데이터가 표시되며, 실거래 API는 로컬 서버 실행 시 환경변수로 연결합니다.

로컬 실행 방법은 [프로젝트 README](gyeongsan-dashboard/README.md)를 참고하세요.
